# Factory AX VERIFY — Windows 원클릭 합성 검수 (소유자 전용)

**RELEASE HOLD / 85% 인수 미확정.** 이 패키지는 서명된 설치 프로그램이 아니며 Python 3.11 이상이 별도 설치돼 있어야 합니다. 실고객 파일·ERP/OT·관리자 권한·네트워크 연결이 필요하지 않습니다.

## 사용 방법

1. 신뢰하는 원본 ZIP을 일반 Windows 10/11 PC의 별도 새 폴더에 압축 해제합니다. 경로는 한글이나 공백이 있어도 됩니다.
2. 폴더의 `RUN_FACTORYAX_WINDOWS_QA.cmd`를 더블클릭합니다. 관리자 권한이나 PowerShell 실행 정책 변경을 하지 마세요.
3. 콘솔의 `SYNTHETIC WINDOWS QA PASS` 또는 `FAILED/BLOCKED`를 확인합니다. `RESULT_FILE:` 뒤에 나타난 **JSON 결과 파일만** 확인한 뒤 필요하면 공유합니다. 경로는 Windows 사용자 임시 폴더에 생성됩니다.

검사는 원본 소스 SHA-256, Python 구문, 전체 단위 테스트, 4종 한글 합성 입력 대사, 보고서 해시, 백업·복원, 독립 `.pyz` 패키지, 실제 Windows `.cmd` 정상/차단 종료 코드, 보고서 덮어쓰기 방지, Tk GUI 위젯 조작을 포함합니다. 테스트용 임시 업무 파일은 자동 삭제하며, 개인 또는 고객 데이터는 전혀 읽지 않습니다. 이 결과 파일에는 원본 행·계정·호스트명·사용자 이름을 넣지 않습니다.

SHA256 manifest는 전송 오류를 잡는 용도일 뿐 **전자서명/작성자 인증이 아닙니다**. 백신/EDR 경고 시 우회하거나 예외 등록하지 말고 검증을 중단하세요. 백신 탐지·Windows ACL/junction/원자적 4파일 스냅샷·실고객 업무 시나리오·공급망/라이선스 인수는 별도 검증 대상입니다.

콘솔에 `Python`을 찾지 못했다는 오류가 표시되면 설치 설정 확인만 하고 환경·보안정책을 임의로 바꾸지 마세요.

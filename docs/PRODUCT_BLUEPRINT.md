# 최종 제품 설계도 v1.0 — Factory AX On-Prem Ecosystem
> 2026-11-12 KST · **장기 최종 100% 범위 기준** · 설계 승인·개발·고객 납품·상업 출시와 구별. 향후 제품 범위 축소는 명시적 소유자 승인.

## 북극성: 보수적인 내부 자료까지 안전하게 AX화
공장·제조기업·보안 요구가 높은 조직이 기존 Excel, 설비/품질 기록, 매뉴얼, NAS 공유폴더, 사무용 PC의 자료를 외부 SaaS에 보내지 않고 **표준 검수·근거·승인·업무 자동화·IT 진단**으로 연결한다. 최종 사용자는 프로그램에서 업무 규칙, 실시간이 아닌 승인된 자료, 실행 이력, 조치 보류와 차단을 이해하고 통제한다.

**상업 모델**은 self-serve가 아니라 **공급자가 미리 구성한 표준 제품+한정된 매핑/정책/설치/인수검사 납품**. 납품 뒤 고객 담당자는 일상 실행만 한다. `SMAX²`는 외부 별도 SELF 플랫폼이고 `Factory AX Configurator`는 공급자 내부의 설정 도구다. 필요 시 PREP 검증된 계약만 가져온다.

## 고객 유치 → 운영까지 4계층
1. **L1 진입 제품(독립 판매)**: CORE + VERIFY — CSV/XLSX 네 데이터: 발주/생산/검사/출하. LOT/단위/품목/수량/기간/부분 출하/재작업 등 사전 규칙과 원본 증거로 대사.
2. **L2 문서·파일 확장**: KNOWLEDGE (승인된 내부 문서의 근거 검색/제한 Q&A); FILE (로컬/SMB 검사성적서·도면·납품 준비/버전 검증); DBVORA 기반 데이터 인벤토리/복원 검증은 이후.
3. **L3 승인형 AX 자동화**: HAE(업무 설명·설계/승인/관리) + Lightning Azent(typed workflow/승인된 단계 실행/스케줄/중복 방지/실패 복구) + SOVIA(위험·감사), **정책 집행은 Security Guard가 독립**. 읽기 전용 정기검사 → 고객 승인 후 제한된 파생 DB/보고 저장 → 고객 허가된 비고위험 자동화 순으로 확장.
4. **L4 보안·운영 관리**: Security Guard(실행/경로/권한/외부 전송 정책), PC CARE(일반 Windows 업무용 PC read-only 건강 점검/주간 변경 추이), Code QA(승인된 소스/스크립트 정적 검토), 통합 Control Console(제품/잡/자산/감사/복원/보고/승인). PLC/ICS 안전제어는 범위 밖.

## 첫 실제 상품 — Factory AX VERIFY 표준 고객 여정
1. 고객이 기존 Excel/CSV 내보내기 파일 **4종, 원래 양식을 복사해 승인된 업무 PC**에서 선택(원본 영구 불변).
2. 공급자가 구성한 회사 업무 프로필(컬럼 별칭/LOT·품목 키·단위 변환·수량/기간/부분 출하·반품·재작업 정책) 불러오기.
3. 형식·해시·변경시각·파일 크기·암호화/매크로/수식/경로·권한 선검사. 이상 시 **BLOCKED**.
4. PREP 호환 규칙으로 자료를 표준 스키마에 변환하되 계산 차이·결측·의미 미확정은 **REVIEW_REQUIRED**. 고객 승인 없이는 자동 열 의미 채택 안 함.
5. EAI 기반 품질 게이트(누락·중복·참조 키·범위) + 신규 제조업 규칙(1:N 주문/생산/검사/출하, 단위/LOT/시간창·분할 출하) 결과 검증.
6. 고객 UI에서 검사 상세(사내 제한 보고서)와 고객 공유용 최소화 보고서, 실제 원본행/파일·규칙 버전·기록시간·해시·사람 검토 상태 표시.
7. 고객 담당자가 **확인/보류/추가 확인**. 원본 보고서/양식은 수정하지 않으며, 유효한 파생 결과만 별도 파일로 출력.
8. 재실행/스케줄링은 별도 승인·실행 시 원본 SHA/정책 버전 확인. 담당자 교체/오프라인/권한 실패/손상된 출력 복구/재점검 경로 제공.

## 조직용 최종 사용 화면
- `홈`: 지난 점검, 보류·오류·승인 대기, 이번주 업무용 PC 상태(옵션).
- `자료`: 승인 받은 회사 데이터 자산만 등록, 출처/스키마/최근 상태/해시.
- `검수`: 지원되는 검수 템플릿 선택 → 파일 → 미리보기 → 실행 → 근거 보고서.
- `지식`: 매뉴얼/작업표준서 검색, 문서 버전과 페이지, 근거 없으면 답변 보류.
- `자동화`: 업무 템플릿/사람 승인/시간표/실행 이력/리트라이/중지.
- `보안/감사`: 정책/실행 허용·차단 이유/승인/역할·내보내기 통제.
- `PC/코드`: 업무 PC read-only 건강 점검/승인된 코드 정적 검토, 절대 OT 자동 수리 아님.
- `관리`: 백업/검증 복원/오프라인 업데이트/권한/라이선스/지원 범위.

# Factory AX 단계별 개발·수익화·장기 진화 계획
> 확정 사업 방향 / 미확정 구현 범위·시장 가격 가설. 2026-11-12 KST.

## 전체 진화 — 4개의 독립 출고 게이트
| Phase | 제품 묶음 | 개발 우선 | 사업/기술 성공 조건 |
|---|---|---|---|
| **W1** | Factory AX CORE + VERIFY | **현재 최우선** | 사용자가 승인한 4종 제조 자료를 안전하게 대조·근거 보고, Windows 오프라인 고객형 설치·유료 가치 검증 |
| **W2** | KNOWLEDGE + FILE | W1 실제 수락 뒤 | 허가된 매뉴얼 검색/인용과 로컬/SMB 파일 검수, 다고객 템플릿 유효성 |
| **W3** | HAE + LA + Guard + DBVORA 연계 | W2 후/필수 권한 설계 선행 | typed workflow·사람/정기 승인, 기록/재실행/복구/실제 접근통제 |
| **W4** | PC CARE + Code Checker + 보안 관제 + Control Console | W3 신뢰 경계 이후 | 일반 업무 PC read-only 건강 점검, 경고·감사, 코드 정적 검사, 고객 자산/업무 관제 |

**장기 목표는 '보수적 산업까지 내부 자료의 AX화'**이지 단순 엑셀 검사기 판매에 영구 고정하는 것이 아니다. 단, W1 판매/정확성/제품 재사용이 검증되기 전 전체 통합 납품과 방산/OT 진출 약속 금지.

## W1 목표 체크포인트
- **P0 설계/원천 조사 (현재)**: GitHub 소스 계약/권리, PREP Node vs Python port 성능/비용/테스트 비교, EAI 검수 범위, 제조업 4자료 스키마·정답 synthetic fixture 10종, 기술/라이선스 가드.
- **50% 엔지니어링 기준**: 안전한 입력·CSV/XLSX 표준화 + deterministic 품질 엔진 + 원본 해시·예제 최소 실제 데이터 흐름, 독립 회귀와 정상·비정상 검증.
- **70%**: 발주/생산/검사/출하 4종·LOT·부분 출하·재작업 등 예외 정책의 전체 조인/실행·한글 GUI 기본, 중단/중복/오류 및 보류 근거.
- **85%**: Windows 설치 가능한 1개 고객 패키지, 전체 회귀·보안·파일 경로·결과 보고/지원 메타/오프라인 시뮬레이터; 100% 의미 아님.
- **95%**: 실제 Windows 10/11(고객형)·오프라인, 대용량·한글·잠금/권한/경합·재시작/백업 복원, 무외부전송 확인, 가격/시장 수용성 일부 실증.
- **100% W1**: 실제 고객 승인 시나리오 인수, 계약 범위·기능·라이선스/OS 호환/설치·업데이트·버그 수용/설명서·기능/보안 검증, 판매/출시 소유자 승인. W1만 출시. W2~W4 여전히 별도 미완.

## 구현 순서 — W1 현금 수익 관점
1. 무료 Excel/Power Query 대비 정말 다른 고객 문제가 있는지 검증: 4원천 파일과 고객 업무 규칙의 교차 검수, 근거·추적, 안전한 반복 매핑.
2. 3개의 대표 가상 공장 스키마와 정상/의도적 오류 정답 자료. 최소 10개 예외(분할 출하·재검·반품·결측·중복·품목 혼재·단위/날짜·LOT) 비교.
3. CORE/EAI 최소 실행 엔진 → 고객 프로필 설정/검토 도구(공급자용 Factory Configurator) → GUI·HTML/Excel 보고서 → Windows 번들.
4. 판매용 데모에서는 허구 자료로 먼저, 고객의 보안 자료는 필요 최소한의 계약·사내 승인·온프레미스 검수 절차로만.
5. 크몽 등록/직접 계약/파트너 판매를 각각 채널 가설로 시험; 실제 사업자/세금/현장 접근/지원 범위·보증 판단. 최초 파일럿 1건과 재사용 테스트 3곳은 **목표치**이며 현재 고객 0 검증.

## W2–W4 상세
- **W2 KNOWLEDGE**: 매뉴얼/TXT/Markdown/PDF 파서·권리·색인/버전·접근권한 → BM25/로컬 임베딩 근거 검색 → 평가문항 gold+미답변 거부 → 선택 로컬 LLM(구매 기업 HW·모델 라이선스 확인). AI 무오류·3초 대답 광고 금지.
- **W2 FILE**: 파일 체크리스트·버전/해시/드리프트 → Windows 폴더 → 승인된 SMB 다제조사 실제 접근. NAS 내부 실행/파일 수정은 별도 상품 전에는 지원하지 않음.
- **W3**: HAE 목표/승인 화면과 LA 실제 제한된 읽기 흐름/SQLite→가변 데이터 결과·계획/원본 SHA/정책/서명/만료 관리; SOVIA advisory 위에 **실제 Security Guard 런타임 거부 강제** → 복구/오류 시 보류/추가승인. 외부 시스템 쓰기는 별도 단계.
- **W4**: PC CARE 수동 건강 스냅샷 → 승인된 Windows Task Scheduler 기반 주기적 read-only 점검→ 비교/경보; Code Checker 승인된 코드 범위 정적 검사→ remediation은 사람이 수행. AV/EDR 및 OT 장비 제어 아님.

## KPI와 Stop/Pivot
- 생산성: 도입 전 수작업 분/건, 도입 후 분/건, 오류 탐지/오탐/미탐, 고객 인수 기록(실증).
- 제품화: 업체 2번째부터 표준 설정만으로 납품되는 비율, 업체당 설정·지원 시간, 지원 건수, 환불/문의, Windows 설치 실패.
- 유지보수: 소스/OS/라이브러리 공급망 업데이트에 필요한 시간, 고객 자료 유출/권한 위반 여부, 월 실제 서버/API/지원 비용.
- 고객 요청이 지원 스키마/템플릿/보안 경계를 넘고 비용/기한이 과도하면 범위를 제한하거나 거절. 검증없는 100%/납품 일정·매출 약속 금지.

## 고객/비용/경쟁 검증
- 가격 가설 BASIC 249k / 구축형 STANDARD 990k / PRO 2.9m~5m KRW는 [COMMERCIAL_MODEL.md](COMMERCIAL_MODEL.md).
- 무료 Excel/Power Query 및 기존 무료 도구보다 고객이 사는 이유는 **중복 양식 간 의미 검증·근거·승인·반복 가능한 설정**. 실제 측정 수요 없는 기능은 패키지 핵심에서 제외.
- 개발 기한은 증거 없는 예측을 확정 일정으로 오인하지 않는다. Stage gate별 구현 소요·기술 제약을 검증하며 갱신.

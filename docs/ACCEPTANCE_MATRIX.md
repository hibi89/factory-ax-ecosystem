## 2. 반드시 개별로 검증할 W1 시험 케이스
- **D01** 네 CSV/XLSX 표준 자료 정상 대사와 원본행 증거.
- **D02** 주문 1:N 생산, 생산 1:N 검사/출하, 분할 출하/허용 오차.
- **D03** LOT·품목이 같은지/다른지, 마스터 참조 누락/대체 코드, 중복 상세/고유키 오류.
- **D04** 검사 불량·재검/보류·반품·폐기·재작업 정책에 따른 합계/근거 보류.
- **D05** 수량 소수 정밀도, 단위(개/박스/kg), 날짜/타임존/기간 경계, 음수/0, 데이터 누락.
- **D06** 누락 열·동일 이름·숨어있는 시트·비정상 엑셀/한글·BOM/인코딩·공식 주입 차단.
- **D07** 허용하지 않은 외부 경로·UNC·심볼릭 링크/junction, 접근 권한·파일 잠금·오프라인 차단.
- **D08** 파일 읽기 중 변경/변조·기존 결과 덮어쓰기·중단 후 재실행, 복구 시 원본 바이트 동일.
- **D09** 외부 요청/텔레메트리/유료 모델 호출 0, 로그·보고서 민감 정보 최소화.
- **D10** 현장 사용자 대상 보고서 근거 클릭·추가확인/승인·읽기 쉬운 한국어·업무시간 실제 측정.

# Factory AX 상용화·설득·가격·원가 모델

## 시장 진입 가설
- 첫 고객: 수기/Excel 기반 발주·생산·품질·출하 대사 업무가 반복되는 한국 중소 제조·부품 가공/조립업체.
- 초기 구매 이유: 무료 Excel·Power Query·파일 정리 유틸리티 자체가 아니라 **4개 다른 양식 사이의 정책을 반영한 불일치·누락·LOT 추적과 원본 근거, 반복 가능한 회사 프로필, 보류/승인 보고**.
- 설득 핵심 3요소: **기술 실제 실행 결과 + 범위가 명확한 비용 + 기존 설비 비간섭·보안 검증**.
- 제조업 담당자 메시지: "ERP/MES 교체 없이, 귀사에서 이미 사용하던 Excel 내보내기 파일을 읽기 전용으로 대조하고 누락·차이를 원본 행 근거와 함께 보고합니다." — 실제 검증된 부분에 한해 사용.
- 시장 검증 없는 'AI 직원/인건비 50% 감축/3초 응답/보안 100%' 약속 금지.

## 실제 영업/고객 신뢰 경로
1. 공개 가능한 **합성 오류/정답 테스트 데이터**로 5~10분 데모(데이터 유출/원본 반출 없음). 무제한 상담·무료 실자료 분석은 피함.
2. 사전 적합성 체크: Windows/오프라인/데이터 형식, 2~4종 표준 입력, 사용자의 매핑/정책 승인, 현장 접근·보안·특별 개인정보 범위.
3. 지원 가능하면 표준 요구서+결과·오류 예시+정해진 설치/교육/유지보수 범위와 1회 가격 제시. '현장 데이터는 고객 내부 승인 환경에서만 검증' 원칙.
4. 사전 인수기준을 기록한 **유료 파일럿 1건 목표**. 테스트 수치(검수 시간/오탐·미탐·변경 요청/설치시간) 수집, 고객 동의 없는 실자료·로고/사례 공개 금지.
5. 다른 업체 2~3곳에서 비슷한 데이터로 설정만 바꿔 반복 납품 가능해야 표준 제품으로 본다. 계속 bespoke 코딩이 필요하면 제품 스코프 재축소/가격 재평가.
6. 등록 채널: 크몽(개발/구축 상품의 의무·수수료 확인), 자체 브랜드 쇼룸(고객자료 수집/온라인 결제 없이 데모 가능), 파트너/직접 기업 계약은 별도 규정 검토.

## 유지비 0원의 정확한 범위
- **목표 0원/월**: 기본 고객 앱의 필수 외부 LLM API, 클라우드 DB, 중앙 SaaS 서버, 문자/이메일 발송 서비스 비용. Windows 로컬/SQLite/읽기 전용 PDF·HTML 보고 기반.
- **0원 아님**: 1회 구매/납품비, PC/산업망/전기/인터넷/추가 GPU·모델 설치, 소스 컴포넌트 재배포권/코드서명 비용, 제품 업데이트·백업/지원 인건비, 세금·크몽 수수료·환불, 현장 출장/장비.
- W3 자동화의 정기 실행은 고객 PC/허가된 서버 전원 가동 전제, 꺼져 있을 때 검사 미수행. 고장·배포/OS 업데이트로 지원비 발생 가능.
- 장기 운영 유지보수 상품은 **선택 계약**으로만 제안하되 보안 패치/제품 수명·사용권·버그 무상지원과 유료 개발 영역을 고지.

## 수익성 의사결정(예시 수식, 실적 아님)
- 실제 매출총이익 = 계약 납품가 - 플랫폼·결제 수수료 - 환불/보증 충당 - 설정/설치/지원 실작업비 - 추가 소프트웨어/장비 지출.
- 표준화율 = (고객사별 코드 변경 없이 매핑/설정만으로 납품 성공한 건수) / (총 유상 납품 건수).
- 고객 가치 = 도입 전/후 작업시간 변화·미검출/탐지된 오류·재작업 감소 × 고객이 합의한 단가. **실측 전 50% 절감 수치 주장 금지**.
- 경쟁 무료 대안과 차이 증명 실패, 설정/지원 인건비가 판매가를 잠식하거나 고객이 원본 반출/OT 쓰기 요구하면 **No-Go / Stop & Pivot**.

# Factory AX 결정 기록 (ADR)
> 2026-11-12 KST 사용자 요구를 반영한 총괄의 기획/설계 선택. '승인된 작업 범위'와 '추천 설계'를 분리한다.

| ID | 결정 | 상태/근거 |
|---|---|---|
| ADR-001 | **Factory AX는 SMAX²와 다른 공급자 구축·납품형 사업** | 사용자의 최신 명시 의도. 기존 SMAX² SELF/WEB 정체성 보존 |
| ADR-002 | 제품 전략 **표준제품+한정 설정+인수시험** vs 완전 맞춤 SI/완전 SELF | 총괄 추천. 고객은 완성품 사용, 공급자는 Configurator/매핑 도구 사용 |
| ADR-003 | 제품 최종 목표는 보수적 기업 내부 **HAE+LA 중심 AX 운영 플랫폼** | 사용자의 장기 비전 확정. 4계층 W1~W4 구간 나눔 |
| ADR-004 | W1 판매 초기: **CORE + VERIFY**(Excel/CSV 4자료 대사) | 총괄 추천, 실고객 정확도/구매가 검증 전 |
| ADR-005 | W2 KNOWLEDGE/FILE, W3 Guarded Automation, W4 Endpoint/Code QA | 사용자 장기 요구 반영. 기능/보안/라이선스/실기기 검증 필수 |
| ADR-006 | **SMAX² PREP 계약만 후보**; 플랫폼 전체/REA_Web 전체 설치·무조건 코드 복사 아님 | 사용자 질의로 설계 경계 재확정 |
| ADR-007 | 첫 상품 기본 **Python 단일 고객 런타임 + 어댑터/계약 기반 통합** vs 원천 Node·Python 다중 프로세스 통합 | 총괄 추천; 전처리 코드 동등성/라이선스/성능 확인 후 최종 기술 선택 |
| ADR-008 | **Security Guard 실제 실행 정책**과 **SOVIA 감사** 분리 | 필수 보안 설계. SOVIA만으로 DENY 보장 불가 |
| ADR-009 | PC CARE는 일반 **Windows 업무 PC만 read-only 수동/승인 일정 검사**, AI는 분석/제안 | 사용자 요구에 대한 안전한 구현 범위. 무인 수리/OT 진단 기본 금지 |
| ADR-010 | 필수 외부 유료 AI/클라우드/중앙 서버 **0원/월 설계 목표** | 장비/운영/지원/세금/수수료까지 총비용0원 주장 금지 |
| ADR-011 | Factory AX W1 가격 BASIC 249k / STANDARD 990k / PRO 2.9m~5m KRW | 출시 실험 가설; 구매/경쟁/원가 검증 필요 |
| ADR-012 | Private 저장소, `main` 안정 + `integration/develop` + 큰 기술영역별 브랜치 | 사용자가 저장소 생성·브랜치 구성 요청. 다른 원천 변경 금지 |
| ADR-013 | 초기 OT·PLC·SCADA/MES 쓰기/산업안전 인증·실무 방산 인증 제외 | 위험/권한 부족, 향후 별도 안전성·계약/승인 필요 |

## 미결정·승인이 필요한 질문 (현재 사용자에게 즉시 작업 요청 아님)
- 실제 고객 W1 첫 검수 업무 1개/지원 양식 구성, 입력 제한, 고객 파일/보안 분류.
- PREP 직접 Port vs 어댑터 구현과 상업 라이선스/OSS 저작권, 최종 exe/UI 패키징 선택.
- 소비자 Windows10/11 최소 요구사항, 1대/기업 설치 라이선스, 지원 시간/기간과 환불·유료 추가 기능.
- W2 로컬 모델·임베딩·문서 접근·스토리지 하드웨어 기준.
- W3 정책 집행/OS 사용자 통합·인증/추가 승인 시스템, 서명 방식·고객 보안 요구.
- 실제 고객 접근/자료 반입/설비 영향·유료 지원, 판매/공개/권한·비용 승인.
